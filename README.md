## Project Description
This project is a simple rule-based chatbot developed using Python.
The chatbot responds to user input using predefined keywords and
if-else conditions.

## Features
- Handles greetings such as hello, hi, and hey
- Answers the user's name-related question
- Responds to "How are you?"
- Provides help information
- Gives a fallback response for unknown questions
- Allows the user to exit using bye, exit, or quit

## Technologies Used
- Python
- If-else conditions
- String handling

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

python chatbot.py

## Example

You: hello
Bot: Hello! How can I help you?

You: how are you
Bot: I'm doing great! Thank you for asking.

You: bye
Bot: Goodbye! Have a nice day!
